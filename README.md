# Wiki Standards

Repositório de consulta de normas contábeis, com textos normativos preservados e páginas auxiliares de navegação.

## Como navegar

- `normas/`: textos das normas.
- `catalogo/`: índices, mapas e equivalências entre pronunciamentos.
- `families/`: páginas organizadas por família normativa.
